## Audit Checklist

### 1. Hard Boundaries Check
- [ ] No cyclical dependencies between core and services.
- [ ] Voice service does not import from Memory.
- [ ] Tools do not depend on Voice.

### 2. Infrastructure Encapsulation
- [ ] Redis is fully contained within the `aether-internal` docker network.
- [ ] Qdrant is fully contained within the `aether-internal` docker network.
- [ ] No external processes require hardcoded DB paths outside `data/`.

### 3. Graceful Shutdown Check
- [ ] `stop.ps1` successfully kills all orphaned processes and stops containers.
- [ ] Redis executes a `BGSAVE` or dumps data upon graceful stop.

### 4. Configuration Centralization
- [ ] All services use `aether.core.config.get_config()`.
- [ ] No hardcoded environment variables exist in service logic.

### 5. Memory Initialization
- [ ] Qdrant episodic memory collection is successfully created if missing.
- [ ] SQLite database migrations run successfully automatically or explicitly.

### 6. Event Bus Isolation
- [ ] Redis event bus properly handles pub/sub without leaking state.
- [ ] The `logging` module is thread-safe and writes correctly to `logs/aether.log`.

### 7. Voice Hardware Abstraction
- [ ] The Voice service handles missing Audio Devices gracefully.
- [ ] VAD and Wake Word fall back correctly if keys or devices are unavailable.

### 8. Backup & Restore Validation
- [ ] `backup.ps1` completes without errors and produces a verified manifest.
- [ ] Destructive loss of `aether.db` is successfully recovered by `restore.ps1`.
